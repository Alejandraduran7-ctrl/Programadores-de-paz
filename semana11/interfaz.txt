La interfaz contará con una página principal que muestra el mensaje de bienvenida y las opciones de acceso. Dispondrá de un formulario claro para registrar un nuevo reporte: tendrá campos para seleccionar el tipo de problema, escribir la descripción breve, indicar el barrio o zona y marcar la casilla de confirmación de no incluir datos sensibles.
 Luego se verá una lista ordenada de los reportes comunitarios registrados, mostrando solo el tipo de problema, la zona, la fecha y el estado actual. Cada reporte tendrá un botón para ver más detalles y, si el usuario tiene permiso, un botón para agregar una actualización o comentario de seguimiento.
 En la lista se incluye un contador que indica cuántos reportes hay pendientes de revisión y cuántos han sido resueltos. El diseño será sencillo, con letras legibles, colores contrastantes y sin elementos innecesarios, evitando siempre mostrar nombres completos ni información privada de quien reporta
